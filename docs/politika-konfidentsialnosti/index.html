Политика в отношении обработки персональных данных

Редакция от 13 октября 2026 г.

1. Общие положения

1.1. Настоящая политика составлена в соответствии с Федеральным законом от 27.07.2006 № 152-ФЗ «О персональных данных» и определяет порядок обработки персональных данных и меры по обеспечению их безопасности, которые принимает ООО «Драфт Мебель» (ИНН 1800036907) (далее — Оператор).

1.2. Политика применяется ко всей информации, которую Оператор может получить о посетителях сайта https://mihailburmasov.github.io/Draft_mebel/ (далее — Сайт).

1.3. Контакты Оператора: телефон +7 951 198-66-88, адрес: г. Ижевск, ул. Орджоникидзе, 4.

2. Какие данные мы обрабатываем

2.1. Имя (по желанию пользователя) и номер телефона, которые пользователь указывает в форме расчёта стоимости.

2.2. Ответы на вопросы формы: вид мебели, форма и примерный размер, желаемые сроки, наличие проекта, удобный способ связи.

2.3. Технические данные, которые автоматически передаются при посещении Сайта: cookie, IP-адрес, сведения о браузере. Сайт не использует сервисы веб-аналитики и рекламные счётчики.

3. Цели обработки

3.1. Связаться с пользователем по его заявке, рассчитать стоимость мебели, договориться о замере.

3.2. Подготовить и заключить договор на изготовление мебели, если пользователь этого захочет.

3.3. Обеспечить корректную работу Сайта.

4. Правовые основания

4.1. Персональные данные из формы обрабатываются на основании согласия пользователя, которое он даёт, отмечая соответствующее поле перед отправкой формы. Текст согласия размещён на странице «Согласие на обработку персональных данных».

5. Порядок обработки

5.1. Оператор обрабатывает данные с использованием средств автоматизации и без них: сбор, запись, систематизация, хранение, уточнение, использование, удаление, уничтожение.

5.2. Оператор не продаёт персональные данные и не передаёт их третьим лицам, кроме случаев, предусмотренных законодательством РФ.

5.3. Данные хранятся до достижения целей обработки, но не дольше одного года с последнего обращения пользователя, если между сторонами не заключён договор. После этого данные удаляются.

5.4. Оператор принимает правовые, организационные и технические меры для защиты данных от неправомерного доступа, изменения, распространения и уничтожения.

6. Cookie и сторонние сервисы

6.1. Сайт использует cookie и локальное хранилище браузера, чтобы корректно работать (например, запомнить, что пользователь закрыл уведомление о cookie).

6.2. На Сайт встроена Яндекс Карта (ООО «Яндекс»). Она может устанавливать собственные cookie по правилам Яндекса. Пользователь может отключить cookie в настройках браузера — Сайт при этом продолжит работать.

7. Права пользователя

7.1. Пользователь вправе получить сведения об обработке своих данных, потребовать их уточнения, блокирования или удаления, а также отозвать согласие на обработку.

7.2. Для этого достаточно обратиться к Оператору по контактам из п. 1.3. Оператор ответит в сроки, установленные 152-ФЗ.

8. Заключительные положения

8.1. Оператор может изменять политику. Новая редакция действует с момента публикации на Сайте.
